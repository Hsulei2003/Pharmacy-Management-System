# Pharmacy Management System

Desktop Pharmacy Management System developed using Python Tkinter and SQLite.

## Features

- User Authentication
- Dashboard
- Category Management
- Supplier Management
- Add Medicine
- Batch Inventory
- Barcode Scanner
- POS Scan & Sell
- FIFO Stock Deduction
- Audit Logs
- User Management

## Technologies

- Python
- Tkinter
- SQLite
- OpenCV
- ZXingCPP
